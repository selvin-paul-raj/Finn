# TASKS.md — Flat Build Task List

Derived from `AGENT.md` §2. One task per file/behavior. Work top to bottom;
each dependency precedes what depends on it. Check `[x]` only when the full
TDD loop (failing test → passing test → full suite green) is complete for
that task — never on partial work.

Test/impl pairs: the odd task writes the failing test, the even task right
after it writes the minimum code to pass that test, then runs the full
suite.
